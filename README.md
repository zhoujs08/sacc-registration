# SACC 比赛项目

这是仓库的 `bisai` 分支，用于归纳正式比赛报名网页及相关资料。

## 主要入口

- `比赛内容/sacc-zhengshiban.html`：SACC 比赛报名主页面，双击即可预览。
- `比赛内容/bisai-jianjie.html`：比赛信息介绍页面。
- `比赛内容/nanjing-youdian-daxue.html`：南京邮电大学介绍页面。

## 样式与功能

- `比赛内容/sacc-zhengshiban.css`：比赛报名页面样式。
- `比赛内容/submit.js`：报名提交、数据保存、删除和截止时间倒计时。
- `比赛内容/yishu-ziti-xuanran.css`：南京邮电大学页面艺术字体样式。
- `比赛内容/bisai-css-changyong-xiushi-xuexi-biji.css`：比赛阶段整理的 CSS 注释笔记。
